## 5. Featured Projects

<details>
<summary><strong>🌾 Krushi_connect — AI-Powered Agricultural Logistics & VRP Optimization</strong></summary>

**Professional explanation:** An end-to-end agricultural logistics platform concept designed to connect crop movement, pricing, perishability, and route planning in one system.

- **Stack:** React, Vite, Tailwind CSS, React Leaflet, Zustand, Node.js, Express, MongoDB, Socket.io, Python, FastAPI, LightGBM, Google OR-Tools, Docker.
- **Scale:** Structured as a multi-service monorepo with separate frontend, backend, and AI-engine areas.
- **Performance:** Uses route optimization and geospatial matching concepts; no production benchmark is claimed.
- **Security:** Repository documentation describes JWT authentication, role-based access control, Helmet, rate limiting, and logging.
- **Impact:** Demonstrates how prediction, spoilage modeling, route optimization, and real-time logistics can be combined for an agricultural workflow.
- **Repository:** [Open Krushi_connect](https://github.com/adityachavan0704-web/Krushi_connect)

</details>

<details>
<summary><strong>🧾 FakeRx — Fake Prescription Detector</strong></summary>

**Professional explanation:** A full-stack application that uses OCR and rule-based analysis to identify potentially fraudulent or manipulated prescriptions.

- **Stack:** React 19, Vite, Express, MongoDB, Mongoose, Flask, EasyOCR, OpenCV, JWT, Axios.
- **Scale:** Organized as three services: frontend, backend, and ML service.
- **Performance:** Separates OCR processing into a dedicated service; no production latency or throughput figures are claimed.
- **Security:** The repository includes authentication, password hashing, request validation, and environment-based configuration.
- **Impact:** Shows practical integration of document processing and healthcare-oriented verification into a web application.
- **Repository:** [Open FakeRx](https://github.com/adityachavan0704-web/FakeRx)

</details>

<details>
<summary><strong>💊 Medicine-Manager — Smart Medicine Inventory System</strong></summary>

**Professional explanation:** A medicine inventory management application that demonstrates how classic data structures can support expiry tracking, alerts, search, and operational history.

- **Stack:** React, Vite, Tailwind CSS, React Router, Recharts, Axios, Node.js, Express, MySQL, JWT, Bcrypt.
- **Scale:** Implements a three-tier application structure with frontend, backend, and database layers.
- **Performance:** Documents O(1) average lookup goals using a custom HashMap and O(log n) heap operations for expiry prioritization; these are algorithmic properties, not production benchmarks.
- **Security:** Includes JWT authentication, password hashing, role-based access control, SQL-injection prevention, rate limiting, and CORS controls as documented by the project.
- **Impact:** Connects data-structure concepts to a practical healthcare inventory workflow.
- **Repository:** [Open Medicine-Manager](https://github.com/adityachavan0704-web/Medicine-Manager)

</details>

<details>
<summary><strong>🛒 Becho — Marketplace and Mentorship Platform Concept</strong></summary>

**Professional explanation:** A TypeScript-based full-stack application concept with marketplace listings, user roles, mentorship, messaging, and a relational data layer.

- **Stack:** React, TypeScript, Vite, Node.js, TypeScript backend, Supabase PostgreSQL, Prisma, and PostgreSQL drivers.
- **Scale:** Split into `frontend` and `backend` services with database documentation and Prisma schema workflows.
- **Performance:** Uses a relational schema and ORM-based data access; no production performance figures are claimed.
- **Security:** Repository documentation references password hashing, authentication flows, roles, refresh tokens, and database-backed authorization concepts.
- **Impact:** Demonstrates product-oriented full-stack development beyond a single-page interface.
- **Repository:** [Open Becho](https://github.com/adityachavan0704-web/Becho)

</details>
